# Project instructions

## Headings and subtitles

- Use very few subtitles.
- Add a subtitle only when it is necessary for navigation or understanding.
- Do not add decorative, motivational, or repeated subtitles.
- Prefer clear content and spacing over extra headings.

## Course content

- Make every chapter clear without the source PDF open beside it.
- Blend all useful source material into one connected explanation.
- Do not present a chapter as a long run of equal paragraphs.
- Use content-based visual reading aids.
- Use a timeline for chronological material.
- Use a side-by-side layout for concepts that readers must compare.
- Use numbered steps or a flow diagram for a process.
- Use a dialogue layout for a conversation.
- Use short highlights for key conclusions.
- Use quotes only for real source text.
- Show the source or PDF page for each quote.
- Do not turn full explanations into short bullet lists.
- Keep every visual aid useful for learning.
- Keep all necessary content available without JavaScript.
- Check each visual aid on phones, in print, and in light and dark themes.
- Follow `IMPLEMENTALASI_SZABALYOK.md` for the full rules.
